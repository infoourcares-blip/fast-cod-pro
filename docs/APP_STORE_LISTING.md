# Fast COD Pro App Store Listing

## One-line value proposition

Fast COD Pro helps COD-first Shopify stores add a branded product-page popup that creates Shopify COD orders and opens Shopify's native order status page.

## Short description

Launch a configurable storefront COD popup for cash-on-delivery stores. The popup collects delivery details, creates a Shopify order with Cash on Delivery as a pending payment, and redirects shoppers to Shopify's native order status page.

## Full description

Fast COD Pro is built for merchants who want a fast product-page COD flow. Add a branded COD button, customize label, color, icon, animation, and popup fields, then create a Shopify order and send shoppers to the Shopify-hosted order status page.

### Core features

- Product-page COD popup button
- Creates Shopify orders with Cash on Delivery as pending payment
- Redirects shoppers to Shopify's native order status page
- Customer contact, shipping, billing, and custom details saved on the Shopify order
- Button label, color, icon, animation, and corner controls
- Popup field controls with add, hide, delete, and reorder
- Embedded admin dashboard with onboarding and launch-readiness sections
- Billing plans through Shopify Billing

### Best-fit merchants

- COD-first stores that need a faster product-page order form
- merchants who want a prominent product-page COD CTA
- teams that need theme-level button and popup controls while keeping final order records inside Shopify

## Shopify review notes

Fast COD Pro uses `read_products` to show product context, `write_app_proxy` to load storefront configuration, `write_orders` to create Shopify COD orders, and `write_customers` to attach phone-only customer contact details when needed. Shoppers are redirected to Shopify's native order status page after the Shopify order is created.

## Reviewer Test Instructions

1. Install Fast COD Pro on the provided development store.
2. Open the embedded app from Shopify admin and confirm the dashboard loads.
3. Open COD Form and verify button label, colors, icon, animation, and popup fields are configurable.
4. Open the theme editor, enable the Fast COD Pro theme app block on a product template, and save.
5. Visit a product page and click the Fast COD Pro button.
6. Fill the COD popup form and place the order.
7. Confirm a Shopify order is created with COD payment pending, shipping/billing address, and a Shopify order status page redirect.
